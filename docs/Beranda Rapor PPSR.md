# Rapor PPSR

Pusat catatan proyek sistem manajemen rapor madrasah. Folder kode proyek ini juga menjadi vault Obsidian.

## Mulai di sini

- [[Peta Fitur Rapor PPSR]] — fitur dan lokasi implementasi.
- [[Relasi Data Rapor PPSR]] — hubungan model utama.
- [[Panduan Pengembangan Rapor PPSR]] — aturan kerja dan Laravel Boost.
- [[Catatan Pemeriksaan Rapor PPSR]] — fakta dan batas pemeriksaan saat ini.
- [[Template Catatan Pengembangan]] — salin untuk mencatat pekerjaan berikutnya.

## Cara memakai vault

Gunakan Quick Switcher untuk membuka catatan, Backlinks untuk melihat hubungan, dan Graph View untuk peta catatan. Catatan baru disimpan di `docs`.

Untuk memakai template, buat catatan di `docs`, lalu jalankan perintah **Templates: Insert template** dan pilih Template Catatan Pengembangan.
